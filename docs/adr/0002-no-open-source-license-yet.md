# ADR 0002: Public repository without an open-source licence (for now)

- **Status:** Accepted
- **Date:** 2026-10-16

## Context

The repository is public so that it can serve as a portfolio in software development and cybersecurity, and to demonstrate that the system's security does not depend on hidden code. At the same time, the project may later become a paid service for artists. An open-source licence, once granted for a version of the code, cannot be withdrawn for that version.

## Decision

Publish the code **without a licence**. Copyright remains with the author: *All rights reserved.*

## Consequences

- Anyone can read the code. GitHub's terms of service also allow other users to view and fork public repositories on GitHub, but no rights are granted to copy, modify, distribute or use the code elsewhere.
- Outside contributions are not expected at this stage.
- The option to adopt an open-source licence later – for all or parts of the code – remains open.

## Review

Revisit before v1.0 (test users) and before any commercial launch.
